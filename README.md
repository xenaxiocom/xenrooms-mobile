# XenRooms for phones

The chat app of [Xenaxio](https://xenaxio.com) for Android and iPhone: the
Rooms of your companies, switching between them without signing in again, as
on [xenrooms.app](https://xenrooms.app). React Native (Expo SDK 54, React
Native 0.81), open source under the AGPL-3.0 with a permission for app stores
(see [LICENSE](LICENSE)).

Status: **R0, the skeleton** — the app starts in the theme and language of the
device. Sign-in, companies and chat come with R1 (the platform's plan, step 152).

## Layout

| Path | What |
| --- | --- |
| `apps/xenrooms` | The app (`com.xenaxio.xenrooms`). `android/` and `ios/` are generated by `expo prebuild`, never committed. |
| `packages/rooms-native` | `@xenaxio/rooms-native`: Rooms for React Native — theme, texts, and (from R1) the screens. The Xenaxio app (`xenaxiocom/native`) shows the same package as its Rooms tab. |
| `scripts/` | Texts and icons from the web client, the license check. |

The package has no sign-in of its own: the host app signs in through the
Xenaxio platform (a device token per company) and passes the company's
address, the token, the language and the theme (`RoomsHost`).

## Develop

```sh
pnpm install
pnpm check                 # types, tests, licenses of what is in the app, texts
cd apps/xenrooms && npx expo start
```

Node 22 and pnpm 10. `node-linker=hoisted` (`.npmrc`) keeps `node_modules`
flat, as Expo and Metro expect.

### Texts

Rooms says on the phone what it says in the browser: the sections `common`,
`chat` and `rooms` of the web client's `lib/xenaxio/messages-{de,en}.json` are
copied to `packages/rooms-native/locales/`:

```sh
pnpm messages:sync --webmail ../webmail
```

Texts only the app has live in `apps/xenrooms/locales/`. German and English
must have the same keys (`pnpm messages:check`).

### Colours

Screens take every colour from the theme (`useRoomsTheme()`): the web client's
tokens — `background`, `foreground`, `card`, `muted`, `accent`, `primary`,
`border`, `destructive`, `success`, `warning`, `info` and their
`…Foreground` — in light and dark, with the company colour as `primary`. No
hex values or named colours in screens; a test checks it.

### Icons

```sh
pnpm icons --webmail ../webmail   # from public/xenrooms/ of the web client
```

## Release

| Workflow | Makes | Secrets |
| --- | --- | --- |
| `release-android.yml` | A signed APK, attached to the GitHub release | `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` |
| `release-ios.yml` | A TestFlight build | `APPLE_TEAM_ID`, `IOS_DIST_CERT_BASE64`, `IOS_DIST_CERT_PASSWORD`, `IOS_PROVISIONING_PROFILE_BASE64` (App Store profile for `com.xenaxio.xenrooms`), `APP_STORE_CONNECT_KEY_ID`, `APP_STORE_CONNECT_ISSUER_ID`, `APP_STORE_CONNECT_PRIVATE_KEY` |

Without the secrets both workflows still build, to show the build works, but
publish nothing. Both run on a published release or by hand.
